# Среда исполнения агента

Клиент-серверная среда для запуска агентских задач в изолированных Docker-контейнерах. Клиент отправляет задачу по HTTP. Харнес запрашивает следующее действие у прокси и через менеджер выполняет команду в контейнере. После запуска чекер проверяет файлы в рабочей папке, а клиент сохраняет результат и трассу в JSONL

В проекте реализованы пять базовых агентских функций из [курса Agentic LLM Systems](https://github.com/deeppavlov/agentic-course-itmo/blob/main/projects/A-agent-runtime.md): чтение, поиск, создание и правка файлов, вызов инструмента. Для воспроизводимых тестов действия модели задает сценарный прокси. Каждая задача получает временную папку `/work` со своей фикстурой и выполняется без доступа к сети

## Запуск

Нужны Docker с Linux-контейнерами, Docker Compose с поддержкой `--wait`, Python 3.9+, Make и OpenSSL

```sh
make demo
```

Команда создает локальный токен в `.env`, собирает сервисы и запускает все пять задач. В терминале видны ответы и вердикты чекеров. Каждый прогон записывается в отдельный файл в [results/baf/v0-scripted-mock](results/baf/v0-scripted-mock)

На работающем сервере `make baf-smoke` повторяет прогон, `make test-ci` запускает также тесты клиента, харнеса и изоляции. Для остановки сервера -- `make down`
