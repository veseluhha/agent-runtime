Функция `slugify(text)` принимает строку и возвращает строку для адреса страницы

Сохрани латинские буквы ASCII и цифры 0–9, переведи буквы в нижний регистр. Каждую последовательность остальных символов замени одним дефисом. Удали дефисы по краям. Если букв и цифр не осталось, верни пустую строку

Например, для `  Build / RC 3  ` результат равен `build-rc-3`
